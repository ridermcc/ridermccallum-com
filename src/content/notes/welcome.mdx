This is the start of something I want to do for a while.

I think every player, coach, and agent in hockey is going to be using AI tools like Claude Code in the next few years — to plan training, manage their season, study video, handle paperwork, all of it. Most of us are just figuring it out one project at a time.

The plan here is simple: build things in public, share what works, make it easy for the next person to clone what I've made and adapt it.

Two kinds of posts will live here:

- **Tools** I build for myself first, then strip down so anyone can clone them.
- **Notes** about what I'm learning — on the ice, off the ice, and in the code.

If something here helps you, that's the whole point. If you build something cool on top of it, send it my way.
