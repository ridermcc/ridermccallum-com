I started this site to share the things I'm doing because I think it's important.

I find interest in building useful systems for my personal and professional work and beleive atheltes like me will use the tools and software I use to build things to help the world. 

I want to share the process incase others find value in my discoveries and mistakes.

The plan: build stuff, share it, and make it easy for the next person to clone what I've made and adapt it for them.

I built this site alongside Claude Code and the full repo is available on [GitHub](https://github.com/ridermccallum/ridermccallum-com).

Two kinds of posts will live here:

- **Tools** I build for myself, or others, and share.
- **Notes** about what I'm learning / doing + extra.

I hope my sharing helps in the growing entanglement of athletics and technology.
